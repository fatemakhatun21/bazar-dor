# 🛒 BazarDor — বাজার দর

BazarDor is a responsive Bengali market price tracking application built with Next.js. Users can explore daily product prices, compare market prices, and view price increases and decreases.

## 🚀 Key Features

1. **Daily Market Prices** — View daily prices of essential products.
2. **Product Categories** — Browse products by category.
3. **Price Comparison** — View minimum, maximum, average, and market-wise prices.
4. **Authentication** — Sign in and sign up using email/password, Google, or GitHub.
5. **Profile Update & Sorting** — Update user information and sort products by price.

## 🛠️ Technologies Used

- Next.js (App Router)
- React
- JavaScript
- Tailwind CSS
- HeroUI
- DaisyUI
- BetterAuth
- MongoDB
- React Hot Toast

## 🔐 Authentication

BazarDor uses **BetterAuth** with MongoDB and supports:

- Email and Password Login/Registration
- Google OAuth Login
- GitHub OAuth Login
- Protected Product Details Page
- User Profile Update

## 🌐 API

Market price data is fetched from the Programming Hero BazarDor API:

https://openapi.programming-hero.com/api/bazardor
